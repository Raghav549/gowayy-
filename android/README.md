# gowayy for Android

A thin native wrapper around the live gowayy website: everything you see,
including accounts, orders, bookings and the database, comes from the web app.
There is no separate backend or UI.

## Get the APK

GitHub builds it automatically (workflow **Android APK**, `.github/workflows/android.yml`):

* **Direct download:** builds from `main` publish a release called *android-latest*:
  `https://github.com/Raghav549/gowayy-/releases/download/android-latest/gowayy.apk`
* **From Actions:** open **Actions → Android APK →** the latest run, and download the
  artifact `gowayy-apk-…` under *Artifacts*. It is a zip with the APK inside.
* Run it by hand: **Actions → Android APK → Run workflow**.

## What's inside

* `app/src/main/java/in/gowayy/app/MainActivity.java` is a full-screen WebView. It keeps
  you signed in, opens the gallery for photo uploads and sends `tel:`/`mailto:`/UPI and
  outside links to their own apps. It also shows an offline screen with *Try again*.
* The launcher icon is the **gowayy wordmark** (Bricolage Grotesque Bold, "yy" in the
  lilac gradient) on the brand-purple gradient, generated by `tools/make-icons.mjs`.
  It is an adaptive icon, so it works with round, squircle and themed icons.
* The website address is `appUrl` in `gradle.properties`. You can also set a repository
  variable `APP_URL` (Settings → Secrets and variables → Actions → Variables) to point
  the app at another domain without touching code.

## Signing

APKs are signed with the bundled **sideload key** (`keystore/gowayy-sideload.p12`).
The signature stays the same from build to build, so a new APK installs over the old
one. The key is public in this repository. For a private key (needed for the Play
Store, or recommended once real users install the app), add these repository secrets:
`ANDROID_KEYSTORE_BASE64` (base64 of a .jks/.p12), `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS` and `ANDROID_KEY_PASSWORD`. Switching keys means uninstalling
the old app once.
